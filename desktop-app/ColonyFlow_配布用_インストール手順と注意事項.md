# ColonyFlow インストール手順と注意事項

ColonyFlow（マウスコロニー管理システム デスクトップアプリ版）をご利用いただきありがとうございます。
本ドキュメントでは、アプリのインストール手順および初回起動時のセキュリティ解除方法について説明します。

---

## 1. 動作環境

- **対応OS**: macOS 12.0 (Monterey) 以降（macOS Sonoma / Sequoia 対応）
- **対応チップ**: Apple Silicon (M1 / M2 / M3 / M4 チップ搭載の Mac)
- **アプリアイコン**: 仔マウス（Litters）の専用アイコン

---

## 2. インストール手順

1. 配布されたディスクイメージファイル **`ColonyFlow-v2.00-mac-arm64.dmg`** をダブルクリックして開きます。
2. ウィンドウの中に **`ColonyFlow`** アプリ本体と **`Applications`（アプリケーションフォルダ）** が表示されます。
3. **`ColonyFlow`** アイコンを **`Applications`** フォルダへドラッグ＆ドロップしてください。
4. コピーが完了したら、デスクトップ上にマウントされている `ColonyFlow` ディスクイメージを取り出します（ゴミ箱へドラッグ、または右クリックから「取り出す」）。

---

## 3. 初回起動時の注意（セキュリティ警告の解除手順）

メール添付、Google Drive、Webダウンロード等経由で入手したアプリを初めて開く際、macOS のセキュリティ機能（Gatekeeper）により以下のような警告画面が表示される場合があります。

---

### ケース A: 「"ColonyFlow.app" は壊れているため開けません。ゴミ箱に入れる必要があります。」と表示される場合

> **※ アプリが本当に壊れているわけではありません。**  
> Apple の有料開発者公証（年額ライセンス審査）を行っていない学内・共同研究用アプリをインターネット経由で受信した場合、最新の macOS（Sequoia 等）が「安全性が確認できない」として自動的にアクセスを隔離（ブロック）するためにこの表示が出ます。  
> **（「ゴミ箱に入れる」は押さずに「キャンセル」を押してください）**

#### 【解決方法】ターミナルで隔離属性を解除する（最も確実・1行で完了）

1. Mac の **「ターミナル」** アプリを開きます。  
   *（キーボードの `Command` + `スペース` を押し、検索窓に「ターミナル」と入力して Enter）*
2. 以下のコマンドをコピーして貼り付け、**[Enter]** キーを押します：
   ```bash
   xattr -cr /Applications/ColonyFlow.app
   ```
   *※ もし「アプリケーション」フォルダ以外の場所（デスクトップ等）に置いている場合は、`xattr -cr `（末尾に半角スペース）と入力した後に、ColonyFlow.app をターミナル画面へ直接ドラッグ＆ドロップして Enter を押してください。*
3. ターミナルを終了し、通常通り **ColonyFlow をダブルクリック** してください。警告が消えて正常に起動します！

---

### ケース B: 「開発元を検証できないため開けません」と表示される場合

#### 【方法 1】右クリックから開く（一番簡単）
1. **「アプリケーション」** フォルダを開きます。
2. `ColonyFlow` を **[Control] キーを押しながらクリック（または右クリック）** します。
3. メニューから **「開く」** を選択します。
4. 警告ダイアログの右下に **「開く」** ボタンが表示されるので、それをクリックします。
5. **これで macOS に起動が記憶され、2回目以降は通常通りダブルクリックだけで起動できます。**

#### 【方法 2】システム設定から許可する
1. ダイアログで「キャンセル」を押します。
2. Mac の **「システム設定」** ＞ **「プライバシーとセキュリティ」** を開きます。
3. 画面下部に「"ColonyFlow" は開発元を確認できないため、使用がブロックされました」と表示されていれば、その横の **「このまま開く」** をクリックします。
4. Mac のパスワードまたは Touch ID を入力して許可します。
*(※最新 macOS ではここにボタンが表示されない場合があります。その場合は上記の「ケース A」のターミナルコマンドを実行してください)*

---

## 4. データの保存とバックアップについて

- **データの保管場所**:
  - 本アプリの登録データ（ケージ情報・マウスデータ等）は、お使いの Mac 内の安全なローカル領域（アプリ専用内部ストレージ）に自動保存されます。
  - 外部のクラウドサーバー等には送信されませんので、オフライン環境・研究室ネットワーク内でも安全にご利用いただけます。
- **定期バックアップのおすすめ**:
  - アプリ画面右上の「データ管理」メニューから、いつでも **「JSONエクスポート（バックアップ）」** が可能です。
  - 研究データの保全のため、定期的にバックアップファイルを保存しておくことをおすすめします。別の Mac へのデータ移行も、この JSON ファイルをインポートするだけで完了します。

---

## 5. アップデート・再インストールについて

将来的に新しいバージョン（`ColonyFlow-vX.XX.dmg`）が配布された場合は、同様の手順で Applications フォルダへ上書きドラッグ＆ドロップしてください。登録済みのデータはそのまま引き継がれます。
